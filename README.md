# Personal Portfolio Website

## About
A personal portfolio website built using HTML to showcase my skills, projects and professional profile.

## Technologies Used
- HTML5

## Features
- Personal introduction
- Skills and projects showcase
- About section
- Contact information

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/priyanka20042004/html-portfolio.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
